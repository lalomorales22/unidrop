Three steps. Zero friction.

It feels like AirDrop. It just refuses to pick sides.

Xendfile finds your computers automatically and keeps the receiver in control. Your file never takes a detour through a remote server.

01

Find each other

Open Xendfile on both computers. Nearby devices appear automatically over your local Wi-Fi or Ethernet network.

02

Pair once

Confirm a one-time key to create a trusted, certificate-pinned connection between your two devices.

03

Drop and go

Choose a file, select a computer, and send. The receiver sees the sender, filename, and size before accepting.

Small app. Serious capability.

Private by architecture

Security isn't a premium feature. It's the route your file takes.

Xendfile uses TLS 1.3, certificate pinning, mutual pairing, one-time keys, receiver approval, rate limits, and streamed writes with safe filenames.

Install in minutes

One repository. Three native desktop experiences.

Download and unzip the source bundle, then run the installer for your platform. Installation is per-user and does not require root or administrator access.

macOS

Menu bar

Open Terminal in the unzipped folder. Allow Local Network access when macOS asks.

chmod +x install.sh ./install.sh

Windows

System tray

Open PowerShell in the unzipped folder. Allow private-network access when Windows asks.

Set-ExecutionPolicy -Scope Process Bypass .\install.ps1

Linux

AppIndicator

Open a terminal in the unzipped folder. Xendfile uses systemd user services or XDG autostart.

chmod +x install.sh ./install.sh

Verification status

The current immutable source snapshot publishes its exact byte size and SHA-256 above. Future tagged packages will additionally publish a signed manifest, SBOM, and build provenance beside every download.

Current alpha limitation: the source snapshot is delivered by GitHub and does not yet carry the planned Xendfile publisher signature. Its checksum detects changed bytes but does not prove publisher identity. Do not treat it as a signed production release.

Local means local

The alpha client does not report back to us.

Xendfile has no analytics, advertising, telemetry, crash-report upload, account tracking, or Xendfile-operated cloud storage. This notice covers the current local client, not a future hosted service.

Stored on your computer

Your device identity and private key, paired-device trust records, preferences, recent local transfer status, and received files stay on the computer where Xendfile is installed.

  • UninstallIdentity and pairing data are preserved by default so reinstalling does not silently break trust. Explicit removal is available.
  • Received filesStored in your selected download location and never removed by the uninstaller.
  • Future servicesA separate notice will be required before any waitlist, account, relay, billing, or support service collects data.

Visible on your local network

Nearby devices can see the device name, identifier, operating-system family, port, protocol version, and certificate fingerprint required for discovery and pairing.

  • Paired devicesExchange filenames, sizes, transfer status, and the TLS-protected transfer stream.
  • Network operatorMay observe IP addresses, ports, timing, and traffic volume, but not TLS-protected file contents.
